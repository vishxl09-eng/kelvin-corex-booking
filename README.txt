KELVIN COREX — READY TO RUN

1. Install Node.js LTS if needed.
2. Open this folder in PowerShell.
3. Run:
   npm install
4. Run:
   npm start
5. Open:
   http://localhost:3000

Owner dashboard:
   http://localhost:3000/owner.html

Owner password:
   kelvin123

Customer page:
   http://localhost:3000

Appointments are stored in appointments.json.

IMPORTANT:
- This version does NOT use better-sqlite3.
- WhatsApp buttons open WhatsApp with a pre-filled message.
- Fully automatic WhatsApp sending requires WhatsApp Business/Cloud API later.
- Before putting the site publicly online, change ADMIN_PASSWORD in .env.
